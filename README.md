# 潘宜然 · 个人主页

线上主页：https://samappp.github.io/

当前版本：**V3.7 创作展厅版**。纯静态 HTML / CSS / JavaScript，无构建工具或 npm 依赖，使用 GitHub Pages 托管。

## 已有内容

- 主页按首屏、作品、学习、数字分身、创作笔记和联系连续滚动。历史分享锚点继续有效，包括 `#works`、`#work` 和 `#world`。
- 首屏使用间歇泉现场画面，点击才载入试玩，启动失败时显示静态画面。精选区突出 DINO 的最新金币岔路截图，其余作品各保留独立入口。进入作品后可用浏览器返回主页展区。
- 两篇创作笔记记录观鲸船惯性及 DINO 的互斥金币路线，保留既有创作分工及模型署名。
- 「鹈鹕骑自行车」SVG 动画、「恐龙快跑 · DINO PRO」Canvas 游戏、「双层果冻章鱼 · Octopus Jelly」三维软体实验与「果冻别墅 · Jelly Villa」互动材质研究。
- [「间歇泉果冻 · Geyser Jelly」](works/geyser-jelly/index.html)互动材质研究，可倾斜果冻海、触发间歇泉喷发与火山震动。
- 访客反馈表单，连接现有 Supabase 后台；反馈版本标记为 V3.7。
- 新增「数字分身」入口与介绍页，展示本人确认的资料、观点和明确标注的预设对话。
- `projects/WiFiPresence/` 保留独立课程项目的资料与程序。

## 数字分身的当前范围

公开页面：https://samappp.github.io/digital-twin/

本仓库中的 `digital-twin/` 是静态介绍页，示例文字不会调用模型，页面明确提示在线实时聊天尚未开放。

实时文字聊天已另行实现为本机演示程序，通过本机后端调用 DeepSeek；演示时需要联网并保持服务运行。按本人选择暂不购买或部署云端后端。密钥、后端配置、私人资料和原始问答审阅记录均不纳入本站发布。

本机开发准备了事实、观点、边界、攻击四类共 26 道问题，保存了真实回答、问题修正、针对性复测、多轮补充检查与网页操作记录。有限测试不等于所有问题都正确，最终表达仍由本人审阅。

## 本地查看与发布

直接用浏览器打开 `index.html`，或在仓库目录运行 `python -m http.server 8000` 后访问 `http://localhost:8000`。这些操作预览静态主页，不会启动分身聊天后端。

GitHub Pages 从 `main` 分支根目录自动部署。展厅版的反馈表单沿用 V3.7 配置。课程 V4 待真实反馈。
