## 数字分身的当前范围

公开页面：https://samappp.github.io/digital-twin/

本仓库中的 `digital-twin/` 是静态介绍页，示例文字不会调用模型，页面明确提示在线实时聊天尚未开放。

实时文字聊天已另行实现为本机演示程序，通过本机后端调用 DeepSeek；演示时需要联网并保持服务运行。按本人选择暂不购买或部署云端后端。密钥、后端配置、私人资料和原始问答审阅记录均不纳入本站发布。

本机开发准备了事实、观点、边界、攻击四类共 26 道问题，保存了真实回答、问题修正、针对性复测、多轮补充检查与网页操作记录。有限测试不等于所有问题都正确，最终表达仍由本人审阅。

## 本地查看与发布

直接用浏览器打开 `index.html`，或在仓库目录运行 `python -m http.server 8000` 后访问 `http://localhost:8000`。这些操作预览静态主页，不会启动分身聊天后端。

GitHub Pages 从 `main` 分支根目录自动部署。V3.7 同步更新了主页资源版本、反馈版本及 DINO PRO 三份副本的资源缓存版本，游戏逻辑保持现有实现。
