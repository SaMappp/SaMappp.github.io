# DINO PRO · 恐龙快跑加强版

参考 Chrome 离线小恐龙（[dinosaur.game](https://dinosaur.game/)）重制的**加强版**跑酷游戏。
纯前端、零依赖、零构建，5 个运行文件即可直接部署到 GitHub Pages。

核心增强：

1. **金币机制** —— 金币沿"起跳 → 落地"的抛物线铺开，单组可一次跳跃全收；右上角独立计数，拾取时按当前连击倍率计分。
2. **键位重构** —— `W` / `空格` 跳跃，`S` 下蹲，`A` 减速，`D` 加速（按住持续微调）。
3. **变速操控** —— 0.70× ~ 1.60× 实时调速，画面上方有速度表。
4. **触屏支持** —— 移动端自动显示虚拟按键。

## 操作说明

| 按键 | 作用 |
| --- | --- |
| `W` / `空格` / `↑` | 跳跃（**长按跳更高**，提前松开会被截断） |
| `S` / `↓` | 下蹲（**空中按下会加速下落**，用来快速落地） |
| `A` / `←` | 减速，最低 `0.70×` |
| `D` / `→` | 加速，最高 `1.60×` |
| `P` | 暂停 / 继续 |
| `M` | 静音开关 |

移动端：点击画面上半部分跳跃，底部四个虚拟按键对应 减速 / 跳跃 / 下蹲 / 加速。

### 加速减速的手感说明

- **按住** `D` 倍率会持续爬升（约 1.05/秒），**按住** `A` 持续下降（约 1.20/秒）。
- 松开按键后，倍率会**缓慢回归 1.00×**（约 0.62/秒），不会突然跳变。
- 加速能拉开与障碍的距离、但反应时间变短；减速更安全、但金币组通过速度变慢，各有取舍。

## 赛道

- **随机无尽**。每次重开重新抽取开局位置、障碍和金币。按一局的总分刷新无尽纪录。
- **固定挑战**。选择沙丘连跳、赤壁变速或绿洲金币线，再设定 20～120 秒。固定地图随跑动距离向前展开，同一赛道在不同输入速度与不同局中保持相同的障碍和金币位置。时限内完成即保存本模式纪录和对应影子，暂停会暂停计时。
- **个人最佳影子**。完成一次赛道后，以相同赛道及秒数重跑可看见最佳完成轨迹。影子按本局用时回放，没有碰撞。纪录、影子和设置保存在当前浏览器。

## 金币与连击规则

金币弧沿跳跃轨迹采样，关于弧顶镜像。所有金币共用同一转动和浮动节拍。仙人掌弧接近时有起跳提示。

普通金币组留出起跳与落地空间。少数路段提供 3 枚地面金币和 5 枚空中金币，第一枚拾取的金币决定本段路线，另一条会消失。未选路线的金币不影响连击。

### 倍率阶梯

每吃一枚金币，连击数 +1；单枚金币基础分 **10 分**，实际得分 = `10 × 当前倍率`。

| 连击数 | 倍率 |
| --- | --- |
| 0 ~ 7 | `×1.0` |
| 8 ~ 17 | `×1.5` |
| 18 ~ 29 | `×2.0` |
| 30 ~ 44 | `×2.5` |
| 45+ | `×3.0`（上限） |

> 举例：一口气吃掉 20 枚金币 = 7×10 + 10×15 + 3×20 = **280 分**。

### 断连击

**只要有一枚金币从恐龙身后滑出屏幕而没被吃掉，连击立即清零**，右上角连击条会红闪提示。
所以"该不该为了几枚金币冒险起跳"是本作的核心决策点。

## 结算

撞到仙人掌或翼龙后进入结算面板，逐项列出：

- **距离分** —— 位移 × 0.1
- **收集金币** —— 本局枚数
- **金币转化分** —— 按连击倍率累加后的分数
- **总分** —— 距离分 + 金币转化分
- **历史最高分** —— 破纪录时显示「新纪录」徽章
- **累计收集金币** —— 跨局累计，长期成就感

最高分与累计金币通过 `localStorage` 持久化（键名 `dinopro.save.v1`）。

## 障碍与难度

| 障碍 | 尺寸 | 应对 |
| --- | --- | --- |
| 小仙人掌 | 18×34 | 跳（可 1~3 株连排） |
| 大仙人掌 | 22×50 | 跳，连排时需提前起跳 |
| 低空翼龙 | 离地 8 | **必须跳**，蹲下躲不掉 |
| 中空翼龙 | 离地 34 | **必须蹲**，站着会撞 |
| 高空翼龙 | 离地 52 | 不用管，但**乱跳会撞** |

- 无尽模式的基础滚动速度从 `340 px/s` 随距离线性增长到上限 `640 px/s`。
- 实际速度 = 基础速度 × 玩家倍率，所以**主动减速可以给自己争取反应时间**。
- 无尽模式中，距离分超过 260 后翼龙开始出现，难度越高出现频率越高，高难度下还会成群出现。

### 成群翼龙为什么不会变成死局

翼龙成群时**整群必须是同一个高度**：低空只能跳、中空只能蹲、高空不能乱跳。
一旦混高度，玩家跳完第一只、落地正好撞上第二只 —— 那是无解的死局。

- 同一群的翼龙**紧贴排列**（群内间隙 6~18px），像仙人掌连排一样，
  一次跳跃（低空）或一次下蹲（中空）就能整群通过。
- 群规模按"一次满跳能覆盖多宽"反算：`span = 速度 × 满跳窗口 × 0.72 - 碰撞箱宽`，
  并设**硬上限 3 只**，高速时也不会刷出一整排"翼龙墙"。
- 相邻障碍组的间隔**按时间换算**（`0.70~0.86 秒 × 当前速度`），速度越快像素间距越大，
  保证两个"必须跳"的障碍之间始终留得下一次完整跳跃的滞空距离。

> 验收方式：`.deepworks/tmp/test-dino.js` 里有一个"完美玩家"模拟器（自动在正确时机起跳、
> 中空翼龙落地时下蹲），在满难度 `640 px/s` 下连跑 90 秒，要求 **0 碰撞**。

## 其他特性

- **明暗主题** —— 默认跟随系统，右上角 ☀️ / 🌙 可手动切换并记忆。
- **音效** —— WebAudio 实时合成，无任何音频文件。吃币音高随连击升高，形成阶梯式反馈。
- **粒子与震屏** —— 落地扬尘、吃币爆星、撞击震屏。
- **像素美术** —— 全部精灵由 `sprites.js` 里的字符网格程序化生成，无外部图片，4 倍预渲染保证高清屏锐利。
- **响应式画面** —— 状态栏位于画布之外，任何屏幕宽度都不会遮挡游戏；桌面端可扩大到 2080px，手机端跑道扩展至可用宽度。

## 布局与性能

### 跑道与结算布局

跑道保持 4:1 和 800×200 的逻辑坐标，桌面宽度随窗口调整，矮屏按可用高度缩放。状态栏、模式选择和结算独立排在画布之外。桌面结算使用三列两行，手机竖屏使用两列三行，结果与重开按钮直接显示在页面里。

### 起跳卡顿的原因与修复

卡顿来自**追帧快进**，不是逻辑帧率不够。主循环是 120Hz 固定步长：

```js
acc += dt;
while (acc >= STEP && guard++ < 10) { update(STEP); acc -= STEP; }
```

某帧一旦变慢（GC、样式重排、系统调度），`acc` 就会积压；而 `guard < 10` 允许单帧连补 10 步，
于是下一帧一次性推进 83ms 的模拟量 —— 跳跃弧线看起来就是"顿一下再窜出去"。

修复：把积压上限钳到 `MAX_CATCHUP = 0.10` 秒，`MAX_STEPS = ceil(0.10 / STEP) + 2 = 14` 保证永不截断：

```js
if (acc > MAX_CATCHUP) acc = MAX_CATCHUP;   // 丢弃积压，杜绝追帧快进
```

次要原因一并处理：`updateHUD` 原来每 60ms 无条件写 `spFill.style.width/left/backgroundColor`，
会触发包含画布的 `.stage` 样式重算。现在缓存上次写入的值，**值没变就完全不碰 DOM**；
速度条颜色改由 `data-dir` 交给 CSS（`.sp-fill[data-dir='fast'|'slow']`），不再写内联样式。

## 部署到 GitHub Pages

假设你已经有一个 `<用户名>.github.io` 仓库（个人主页仓库）。

### 方式一：作为子目录（推荐，不会覆盖现有主页）

1. 在本仓库中新建目录，例如 `dino/`。
2. 把 `index.html`、`style.css`、`sprites.js`、`courses.js`、`game.js` 五个运行文件放入 `dino/`。
3. 提交并推送：

   ```bash
   git add dino
   git commit -m "add dino pro game"
   git push
   ```

4. 访问 `https://<用户名>.github.io/dino/` 即可游玩。

### 方式二：在主页加入口

在你主页的导航或卡片区加一个链接：

```html
<a href="./dino/">🦖 DINO PRO · 恐龙快跑加强版</a>
```

### 方式三：独立仓库

新建一个公开仓库（例如 `dino-pro`），把 5 个运行文件推到 `main` 分支，然后在
`Settings → Pages` 中选择 `Deploy from a branch` → `main` → `/ (root)`。
稍等片刻即可通过 `https://<用户名>.github.io/dino-pro/` 访问。

> 注意：所有资源都使用相对路径引用，因此放在**任意子目录**下都能正常工作，无需修改代码。

## 兼容性

Chrome / Edge / Firefox / Safari 现代版本均可。
使用了 `aspect-ratio`、`color-mix()`、`Pointer Events`、`Canvas 2D`、`WebAudio`。

### iOS 长按保护

iOS Safari 长按界面上的任意文字都会把它选中并弹出「拷贝 / 查询 / 翻译」菜单，浮层刚好盖住虚拟按键和游戏画面。
所以整个游戏界面（`html` / `body` / `.app` 及其全部后代：顶栏、状态栏、结算面板、虚拟按键、提示文字、页脚）
统一禁用文字选中：

```css
-webkit-user-select: none;    /* 老版 iOS Safari 只认带前缀的写法 */
user-select: none;
-webkit-touch-callout: none;  /* 关键：关掉长按弹出的系统选择菜单 */
```

`game.js` 再用 `blockNativeSelection()` 给按键区和画布补一层 `contextmenu` / `selectstart` 拦截兜底。
本页是纯游戏页面，没有输入框也没有需要复制的正文，所以全页禁用选中不影响任何正常操作。
（以后若在这页加入链接或输入框，记得在这些元素上把 `user-select` / `-webkit-touch-callout` 恢复回来。）
无尽开局先有一串带起跳提示的金币。一跳全收时会出现提示，之后进入随机赛段。
