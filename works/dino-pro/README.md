# DINO PRO · 恐龙快跑加强版

参考 Chrome 离线小恐龙（[dinosaur.game](https://dinosaur.game/)）重制的**加强版**跑酷游戏。
纯前端、零依赖、零构建，4 个文件即可直接部署到 GitHub Pages。

核心增强：

1. **金币机制** —— 金币沿"起跳 → 落地"的抛物线铺开，单组可一次跳跃全收；右上角独立计数，结算时按连击倍率统一转成分数。
2. **键位重构** —— `W` / `空格` 跳跃，`S` 下蹲，`A` 减速，`D` 加速（按住持续微调）。
3. **变速操控** —— 0.70× ~ 1.60× 实时调速，画面左下角有速度表。
4. **触屏支持** —— 移动端自动显示虚拟按键。

## 操作说明

| 按键 | 作用 |
| --- | --- |
| `W` / `空格` / `↑` | 跳跃（**长按跳更高**，提前松开会被截断） |
| `S` / `↓` | 下蹲（**空中按下会加速下落**，用来快速落地） |
| `A` / `←` | 减速，最低 `0.70×` |
| `D` / `→` | 加速，最高 `1.60×` |
| `P` | 暂停 / 继续 |
| `M` | 静音开关 |

移动端：点击画面上半部分跳跃，底部四个虚拟按键对应 减速 / 跳跃 / 下蹲 / 加速。

### 加速减速的手感说明

- **按住** `D` 倍率会持续爬升（约 1.05/秒），**按住** `A` 持续下降（约 1.20/秒）。
- 松开按键后，倍率会**缓慢回归 1.00×**（约 0.62/秒），不会突然跳变。
- 加速能拉开与障碍的距离、但反应时间变短；减速更安全、但金币组通过速度变慢，各有取舍。

## 金币与连击规则

这是本作与原版最大的差别。

### 分布

金币的核心形态是**跳跃抛物线**：金币沿着恐龙"起跳 → 落地"的真实轨迹铺开，
高度刚好落在恐龙身体中部。所以**在弧线起点起跳，就能把整组金币一次全部收走**。

| 图案 | 权重 | 说明 |
| --- | --- | --- |
| `arc` | 高 | 标准抛物线，5~6 枚，一条完整跳跃弧 |
| `arcTight` | 中 | 短跨度抛物线，3~4 枚，小幅起跳即可收 |
| `ground` | 低 | 贴地金币串，3~4 枚，跑动即可收（节奏调剂） |

此外，仙人掌有约 32% 的概率附带一条**障碍弧**：从障碍左侧起跳、越过仙人掌、右侧落地，
一条完整抛物线正好铺满，跳过去的同一次操作就能把金币收完。

四条硬性规则保证每一组都拿得全：

- **不会同列堆叠** —— 任意两枚金币的水平间距恒大于 26px，不存在"同一横坐标上下各一枚"这种被迫二选一的排布。
- **起跳点与落地点一定是干净的** —— 每枚金币带方向性保护区：弧线**起点只管左侧**（留起跳助跑），弧线**终点只管右侧**（留落地缓冲）。保护区按**时间**换算（保护时间 × 当前速度），所以速度越快、留出的像素距离越大，玩家实际感受到的反应时间始终一致。谁先出现谁占位：金币先来，仙人掌就等它滚远；仙人掌先来，金币组就等路面清空。
- **守卫弧中段刻意不加保护** —— 架在仙人掌正上方的那几枚金币是设计的一部分（"跳过障碍的同时正好收完"），不计入避让。
- **不会互相挤** —— 金币组与既有金币之间也会互相避让，屏幕上永远只会出现一组干净的弧线。

> 保护区参数：起跳点 / 落地点 `0.50 秒`（下限 140px）、弧线中段 `0.20 秒`（下限 80px）、贴地串 `0.28 秒`（下限 100px）。

金币组之间按**时间**计时（1.8~2.5 秒一组），所以无论玩家加速还是减速，密度都保持一致。

> 想让金币更密或更稀，改 `game.js` 里 `spawnCoinGroup()` 末尾的 `rand(1.8, 2.5)` 即可，单位是秒。

### 倍率阶梯

每吃一枚金币，连击数 +1；单枚金币基础分 **10 分**，实际得分 = `10 × 当前倍率`。

| 连击数 | 倍率 |
| --- | --- |
| 0 ~ 7 | `×1.0` |
| 8 ~ 17 | `×1.5` |
| 18 ~ 29 | `×2.0` |
| 30 ~ 44 | `×2.5` |
| 45+ | `×3.0`（上限） |

> 举例：一口气吃掉 20 枚金币 = 7×10 + 10×15 + 3×20 = **280 分**。

### 断连击

**只要有一枚金币从恐龙身后滑出屏幕而没被吃掉，连击立即清零**，右上角连击条会红闪提示。
所以"该不该为了几枚金币冒险起跳"是本作的核心决策点。

## 结算

撞到仙人掌或翼龙后进入结算面板，逐项列出：

- **距离分** —— 位移 × 0.1
- **收集金币** —— 本局枚数
- **金币转化分** —— 按连击倍率累加后的分数
- **总分** —— 距离分 + 金币转化分
- **历史最高分** —— 破纪录时显示「新纪录」徽章
- **累计收集金币** —— 跨局累计，长期成就感

最高分与累计金币通过 `localStorage` 持久化（键名 `dinopro.save.v1`）。

## 障碍与难度

| 障碍 | 尺寸 | 应对 |
| --- | --- | --- |
| 小仙人掌 | 18×34 | 跳（可 1~3 株连排） |
| 大仙人掌 | 22×50 | 跳，连排时需提前起跳 |
| 低空翼龙 | 离地 8 | **必须跳**，蹲下躲不掉 |
| 中空翼龙 | 离地 34 | **必须蹲**，站着会撞 |
| 高空翼龙 | 离地 52 | 不用管，但**乱跳会撞** |

- 基础滚动速度从 `340 px/s` 随距离线性增长到上限 `640 px/s`。
- 实际速度 = 基础速度 × 玩家倍率，所以**主动减速可以给自己争取反应时间**。
- 分数超过 260 后翼龙开始出现，难度越高出现频率越高，高难度下还会成群出现。

## 其他特性

- **明暗主题** —— 默认跟随系统，右上角 ☀️ / 🌙 可手动切换并记忆。
- **音效** —— WebAudio 实时合成，无任何音频文件。吃币音高随连击升高，形成阶梯式反馈。
- **粒子与震屏** —— 落地扬尘、吃币爆星、撞击震屏。
- **像素美术** —— 全部精灵由 `sprites.js` 里的字符网格程序化生成，无外部图片，4 倍预渲染保证高清屏锐利。

## 部署到 GitHub Pages

假设你已经有一个 `<用户名>.github.io` 仓库（个人主页仓库）。

### 方式一：作为子目录（推荐，不会覆盖现有主页）

1. 在本仓库中新建目录，例如 `dino/`。
2. 把 `index.html`、`style.css`、`sprites.js`、`game.js` 四个文件放入 `dino/`。
3. 提交并推送：

   ```bash
   git add dino
   git commit -m "add dino pro game"
   git push
   ```

4. 访问 `https://<用户名>.github.io/dino/` 即可游玩。

### 方式二：在主页加入口

在你主页的导航或卡片区加一个链接：

```html
<a href="./dino/">🦖 DINO PRO · 恐龙快跑加强版</a>
```

### 方式三：独立仓库

新建一个公开仓库（例如 `dino-pro`），把 4 个文件推到 `main` 分支，然后在
`Settings → Pages` 中选择 `Deploy from a branch` → `main` → `/ (root)`。
稍等片刻即可通过 `https://<用户名>.github.io/dino-pro/` 访问。

> 注意：所有资源都使用相对路径引用，因此放在**任意子目录**下都能正常工作，无需修改代码。

## 可调参数

想改手感，直接调 `game.js` 顶部的常量：

```js
var GRAVITY      = 2600;   // 重力，越大下落越快
var JUMP_SPEED   = 700;    // 起跳初速度，峰值高度约 94px
var JUMP_CUT     = 0.40;   // 提前松键保留的速度比例（决定"短跳"下限）
var SPEED_START  = 340;    // 起始滚动速度
var SPEED_MAX    = 640;    // 基础速度上限
var FACTOR_MIN   = 0.7;    // 减速下限
var FACTOR_MAX   = 1.6;    // 加速上限
var COIN_VALUE   = 10;     // 单枚金币基础分
var COMBO_TIERS  = [...];  // 连击倍率阶梯

// 金币分布（抛物线）
var COIN_TRAIL_OFFSET = 22;    // 金币相对跳跃轨迹的高度偏移
var COIN_MIN_GAP      = 26;    // 金币之间的最小水平间距

// 金币与障碍的保护距离（按时间计算：px = 秒 × 当前速度，再取下限）
var COIN_EDGE_TIME   = 0.50;   // 弧线起点左侧 / 终点右侧的保护时间
var COIN_EDGE_MIN    = 140;    // 上述保护距离的下限（px）
var COIN_MID_TIME    = 0.20;   // 弧线中段金币的保护时间
var COIN_MID_MIN     = 80;     // 弧线中段保护距离的下限（px）
var COIN_GROUND_TIME = 0.28;   // 贴地金币串的保护时间
var COIN_GROUND_MIN  = 100;    // 贴地金币串保护距离的下限（px）
```
